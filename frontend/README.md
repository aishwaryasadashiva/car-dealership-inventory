# DriveSpace frontend

React 19 + TypeScript + Tailwind CSS 4, bundled with Vite. See the [root README](../README.md) for full setup.

```bash
npm install
npm run dev      # http://localhost:5173 (expects the API on http://127.0.0.1:8000)
npm test         # Vitest
npm run lint
npm run build
```

Set `VITE_API_URL` to point at a different API base URL (default `http://127.0.0.1:8000/api`).
